**GITHUB**

Joep heeft ons geheugen over GitHub opgefrist.
- GitHub bestaat uit Git en Hub
- Git is een versiebeheersysteem, waarmee je als gebruiker bepaalt welke versie van een bestand moet worden opgeslagen.
- Joep laat de Git-functionaliteit in Visual Studio Code zien aan de hand van een tekstbestand.
Github.com is één van de services (een andere is Gitlab.com) waarin je online gits kan beheren:
- Joep laat zien hoe je nieuwe repository maakt en deze koppelt met de Git op de lokale computer.
- Als je op je lokale master iets wijzigt en commit dan moet je dit ook synchroniseren met Github.com.
- In Github kan je met meerdere mensen aan één bestand werken. Dit levert echter problemen op als mensen tegelijkertijd op dezelfde regel in een bestand werken. 
- Als opmaaktaal gebruikt Github heet 'Markdown'. Het voordeel hiervan is dat je het document in een eenvoudige teksteditor als Notepad kan lezen.
- Met een fork maak je een eigen kopie van een project of een bestand (een andere repository). Je kan op deze manier eerst zelf een code aanpassen en een wijziging later doorvoeren in het oorspronkelijke project. Dit doe je met een pull request.
- Een andere manier om een 'aftakking' van een project te maken is het maken van een branch, dit gebeurt binnen dezelfde repository.
- Benodigde tools om met Github te werken:
   - git-scm.com
   - Visual Studio Code
   - Account github.com

**Printerproject**

Verschillende mensen hebben op basis van de code van Chris hun eerste werkende versie van de printer!
- Let er bij een Raspberry Pi Pico op dat je de uitgangen laag maakt als ze niet worden gebruikt. Als je dit niet doet, wordt de printerkop erg warm!
- Vanwege de ouderdom van de printertjes maken de aansluitingen van de printerkop niet altijd goed contact. Hierdoor ontbreken er rijen in de geprinte letters. Je kan dit oplossen door de contacten even te gummen of met alcohol schoon te maken.
- Expermenteren gaat makkelijker als je de print en het printertje met dubbezijdige tape op een plankje vastzet.
